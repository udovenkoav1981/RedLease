# redlease-tcp-load

Минимальный генератор нагрузки для одного raw TCP-соединения. Он напрямую
отправляет непрерывные пары `Acquire`/`Release`, не используя пакеты `client`
и `client1of1`.

Пары поступают в ограниченную очередь. Один writer забирает все уже доступные
пары, копирует их FlatBuffers frames в 64 KiB write buffer и делает `Flush()`
после опустошения доступной части очереди. Если буфер заполняется раньше,
transport сбрасывает его автоматически. Искусственной задержки для накопления
batch нет. В отличие от публичного клиента, этот генератор отправляет `Release`
сразу после `Acquire`, не дожидаясь ответа: он измеряет пропускную способность
TCP/server pipeline, а не бизнес-семантику lease.

Сначала запустите `redlease-server`, затем:

```bash
go run ./cmd/redlease-tcp-load \
  -target 127.0.0.1:50051 \
  -duration 10s \
  -warmup 1s \
  -keys 1024
```

Клиент сам ждёт завершения restart quarantine. Результат содержит число
завершённых пар `Acquire`/`Release` в секунду и число принятых response messages
в секунду.
