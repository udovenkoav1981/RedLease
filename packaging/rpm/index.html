RedLease RPM repository

Linux x86_64 packages published from RedLease release tags.

sudo curl --fail --silent --show-error \
  https://udovenkoav1981.github.io/RedLease/redlease.repo \
  --output /etc/yum.repos.d/redlease.repo
sudo dnf install redlease-server
sudo systemctl enable --now redlease-server

Server options are configured in /etc/sysconfig/redlease-server. RedLease listens on 0.0.0.0:17379 and the Prometheus exporter listens on 0.0.0.0:17380 by default.

The repository is currently unsigned.
